Capture a new idea from the user's description.

## Instructions

1. Ask the user to describe their idea conversationally (or use the description they already provided)
2. Generate a concise slug from the idea (lowercase, hyphen-separated)
3. Use today's date for the filename: `ideas/YYYY-MM-DD-slug.md`
4. Fill in the idea template from `templates/idea.md`:
   - Write a clear, catchy title
   - Write a punchy one-liner
   - Pick the best-fit category
   - Capture their notes authentically — keep their voice, don't over-formalize
   - Pull out why it's interesting based on what they said
   - Add any references or related things they mentioned
5. Commit with message: "idea: {short description}"
6. Push to the current branch

Keep it fast and casual. The goal is to capture the spark before it fades.
