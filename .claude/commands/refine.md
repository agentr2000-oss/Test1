Tighten up an existing idea or plan — add detail, rethink sections, improve clarity.

## Instructions

1. If the user specifies an idea or plan, find it in `ideas/` or `plans/`. If not, list recent files and ask which one to refine.
2. Read the file thoroughly.
3. Ask the user what kind of refinement they want (or infer from their arguments):
   - **Expand** — flesh out thin sections, add more detail
   - **Tighten** — cut fluff, sharpen language, make it crisper
   - **Rethink** — challenge assumptions, suggest alternatives or pivots
   - **Update** — add new context or information the user provides
4. Apply the refinement directly to the existing file. Preserve the original structure and template format.
5. Keep the tone authentic — don't over-formalize ideas or sanitize the user's voice.
6. Commit with message: "refine: {short description of what changed}"
7. Push to the current branch

Don't rewrite from scratch. Refine means making what's there better, not replacing it.
