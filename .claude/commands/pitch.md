Turn a plan into a short, shareable elevator pitch.

## Instructions

1. If the user specifies a plan, find it in `plans/`. If not, list available plans and ask which one to pitch.
2. Read the plan file and its linked idea file for full context.
3. Write a pitch in this format, and add it as a new section at the bottom of the plan file:
   ## Pitch
   **One-liner:** {A single compelling sentence}
   **The problem:** {1-2 sentences on the pain point}
   **The idea:** {2-3 sentences on the solution and what makes it interesting}
   **Why now:** {1 sentence on timing or urgency, if relevant}
4. Keep it conversational and persuasive — this is something you'd say to a friend or a potential collaborator, not a VC deck.
5. If a Pitch section already exists in the plan, replace it with the new version.
6. Commit with message: "pitch: {plan slug}"
7. Push to the current branch

The pitch should make someone lean in and say "tell me more."
