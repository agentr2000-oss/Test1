Connect related ideas and plans together.

## Instructions

1. If the user specifies two or more files to link, find them in `ideas/` and/or `plans/`. If not, list all files and ask which ones to connect.
2. Read the files to understand their content.
3. For each file being linked, add or update the `## Related` section (for ideas) or add a `## Related Ideas` section at the bottom (for plans) with markdown links to the other connected files.
4. Use relative paths for links (e.g., `[Idea title](../ideas/2026-03-25-slug.md)`).
5. If a link already exists, don't duplicate it.
6. Briefly note *why* the files are related — a short phrase in parentheses after each link.
7. Commit with message: "link: connect {slug1} and {slug2}"
8. Push to the current branch

Think of this as building a web of ideas. The connections are often where the best insights hide.
